Contacts Manager Web Application

A responsive contact management system built with React.js and Tailwind CSS, featuring persistent data storage powered by MongoDB[cite: 1]. The application enables users to perform seamless CRUD (Create, Read, Update, Delete) operations and view real-time updates for contacts[cite: 1].

Features
- Responsive UI: Modern, clean interface styled with Tailwind CSS[cite: 1].
- Full CRUD Operations: Add, edit, delete, and view contact entries seamlessly[cite: 1].
- Persistent Storage: Connected directly to MongoDB for reliable backend data storage and real-time updates[cite: 1].

Tech Stack
- Frontend: React.js, Tailwind CSS[cite: 1]
- Backend & Database: MongoDB[cite: 1]

Getting Started

Prerequisites
Make sure you have Node.js installed on your system.
